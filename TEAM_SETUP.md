# Running the Academic Risk Assistant — Team Setup Guide

This covers everything needed to get the interface (`interface.py`) running on a
teammate's PC: connecting to the trained ML model and to Gemini, end to end.

---

## What you need first

- Python 3.10+ installed
- The project folder (`BelgiumCampus-AcademicRiskAssistant`), containing:
  - `interface.py`, `gemini_assistant.py`
  - `models/` (model.pkl, scaler.pkl, label_encoder.pkl)
  - `requirements.txt`, `.env.example`
- VS Code (recommended) with the **Python extension** installed
- A free Gemini API key (steps below — each teammate needs their own)

---

## Step 1 — Open the project

1. Unzip the project folder somewhere simple, e.g. `Documents\` — **avoid**
   `Downloads`, since browsers often auto-rename repeated downloads to
   `folder (1)`, `folder (2)`, which creates a confusing nested folder.
2. In VS Code: **File → Open Folder**, and select the folder that directly
   contains `interface.py` (not a folder that contains *another* folder of
   the same name — check with the file explorer sidebar first).

---

## Step 2 — Open a terminal in that folder

**Terminal → New Terminal** in VS Code. It should open already pointed at
the project folder. If your prompt doesn't show the project folder path,
`cd` into it manually first.

---

## Step 3 — Create and activate a virtual environment

```powershell
python -m venv .venv
```

Activate it:

- **Windows (PowerShell):** `.venv\Scripts\activate`
- **Mac/Linux:** `source .venv/bin/activate`

You'll know it worked when you see `(.venv)` at the start of your terminal
prompt.

If VS Code shows a popup asking to select this interpreter, click yes — or
manually: `Ctrl+Shift+P` → "Python: Select Interpreter" → choose the one
inside `.venv`.

---

## Step 4 — Install dependencies

With the venv active:

```powershell
pip install -r requirements.txt
```

Run this from inside the project folder — if you get
`Could not open requirements file`, you're in the wrong folder; check
Step 1 again.

---

## Step 5 — Get your own free Gemini API key

Each teammate needs their own key (don't share one key over chat/email).

1. Go to **aistudio.google.com** and sign in with a Google account.
2. Click **Get API key** → **Create API key**.
3. Accept the default project if asked — **no billing/card details needed**
   for the free tier.
4. Copy the key (starts with `AIza...`).

---

## Step 6 — Add the key to a `.env` file

1. Copy `.env.example` and rename the copy to exactly `.env`
   (not `.env.txt` or `.env copy` — Windows sometimes hides file
   extensions, so double check the exact name in VS Code's sidebar).
2. Open `.env` and replace the placeholder so it reads exactly:

   ```
   GEMINI_API_KEY=AIzaSy...your_real_key...
   ```

   No quotes, no spaces around the `=`.
3. Save the file. **Never commit or share this file** — it's your personal
   key.

To double check it saved correctly:

```powershell
dir -Force .env
Get-Content .env
```

---

## Step 7 — Run the app

```powershell
streamlit run interface.py
```

First time only, Streamlit may ask for an email — just press **Enter** to
skip it.

You'll see something like:

```
Local URL: http://localhost:8501
```

Ctrl+click (Cmd+click on Mac) that link, or open a browser and go to
`localhost:8501` manually.

---

## Step 8 — Test it end to end

1. Set the sliders (Attendance, Quiz Average, Assignment Average, Moodle
   Activity, Previous Average) and click **Predict risk level**.
   → You should see a colored Low/Moderate/High risk badge.
2. Wait a moment — a plain-language explanation from Gemini should appear
   underneath it.
3. Type a follow-up question in the chat box at the bottom (e.g. *"Which
   factor matters most here?"*) and confirm you get a relevant answer back.

If you see `GEMINI_API_KEY was not found`, the ML prediction still worked —
only the explanation step failed. Go back to Step 6 and check your `.env`
file's name and contents.

---

## Stopping / restarting

- Stop the app: `Ctrl+C` in the terminal.
- Restart later: reactivate the venv (Step 3) if it's a new terminal
  session, then re-run `streamlit run interface.py` — no need to redo
  Steps 3–6 unless you deleted `.venv` or `.env`.

---

## Do NOT commit or submit

- `.venv/` — regenerated by `pip install -r requirements.txt`
- `.env` — contains your personal API key
- `.idea/` — editor settings, not needed by anyone else
